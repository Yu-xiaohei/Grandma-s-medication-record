## 3. 根因判断

用户那个标签页跑的是 **Service Worker 缓存的旧版本**：

- `public/sw.js` 导航请求是「先返回缓存 HTML，同时后台 fetch 更新」，静态资源是「缓存优先 + 后台刷新，下次打开生效」。
- 用户一直开着同一个标签页（或不完全关闭），就会无限停留在旧 HTML + 旧 CSS。
- GitHub Pages 的 `sw.js` 本身还有 `Cache-Control: max-age=600`，最长 10 分钟内浏览器连新 SW 都拿不到。
